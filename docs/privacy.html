clipbot – Privacy policy

Last updated: 9 November 2026

clipbot is a personal automation tool run by one individual developer (Georgios Kimionakis Sykianakis) for his own YouTube channel. It is not offered to other users.

YouTube API Services

clipbot uses YouTube API Services to upload videos to the owner's own channel. By using clipbot you agree to be bound by the YouTube Terms of Service. YouTube is a Google service, and Google's handling of data is described in the Google Privacy Policy.

What data is accessed

  • Google permission requested: youtube.upload only — used solely to upload Shorts to the owner's channel.
  • Public Twitch clip information (title, streamer name, clip URL) from the Twitch API, for clips the streamers have allowed the owner to repost.
  • No personal data about anyone else is collected, stored, sold or shared. No cookies or analytics are used.

Storage

The Google OAuth refresh token is stored only as an encrypted GitHub Actions secret controlled by the owner. clipbot keeps a list of already-posted Twitch clip IDs so it does not post a clip twice. Downloaded clips are deleted immediately after upload.

Revoking access and deleting data

Access can be revoked at any time at Google security settings. Deleting the GitHub secrets and repository removes all stored data. Requests to delete data can be sent to the contact below and are completed within 7 days.
