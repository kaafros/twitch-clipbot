Privacy policy

Last updated: 9 November 2026

clipbot is a personal automation used only by its owner. It requests one Google permission, youtube.upload, solely to upload videos to the owner's own YouTube channel.

  • It does not collect, store, sell or share personal data from anyone.
  • Google access credentials are stored only as encrypted GitHub Actions secrets controlled by the owner.
  • It reads only public Twitch clip information through the Twitch API.
  • Access can be revoked at any time at myaccount.google.com/permissions.

clipbot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact: open an issue at github.com/kaafros/twitch-clipbot.
